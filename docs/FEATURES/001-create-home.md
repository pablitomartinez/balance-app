# Feature 001 - Crear hogar

## Objetivo

Permitir que un usuario autenticado cree su primer hogar.

## Criterios de aceptación

- [ ] El usuario puede ingresar el nombre del hogar.
- [ ] Se crea un registro en homes.
- [ ] Se crea un registro en home_members con rol owner.
- [ ] Todo ocurre en una única operación.
- [ ] El usuario es redireccionado al dashboard.
