# Capturas reales pendientes

Esta carpeta está preparada para las capturas reales de Balance. Deben generarse con un hogar de demostración, nombres ficticios y movimientos sin información personal.

- `dashboard-desktop-light.webp`: dashboard completo, tema claro, viewport de 1440 px.
- `dashboard-desktop-dark.webp`: dashboard completo, tema oscuro, viewport de 1440 px.
- `dashboard-mobile-light.webp`: dashboard, tema claro, viewport de 390 px.
- `dashboard-mobile-dark.webp`: dashboard, tema oscuro, viewport de 390 px.
- `expenses-mobile-light.webp`: listado de gastos con categorías y estados ficticios, tema claro, viewport de 390 px.
- `services-mobile-light.webp`: solo cuando exista una pantalla real de servicios; no debe recrearse ni simularse.

Exportar en WebP, sin barras del navegador, cursores, datos personales ni información de producción.
